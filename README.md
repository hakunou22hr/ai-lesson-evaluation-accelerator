# AI授業評価 Accelerator

授業の振り返りと授業研究のためのWebアプリです。授業情報、3観点の評価規準、指導上の追加観点、文字起こし、授業分析、概要と全文を含むPDFを順に扱います。評価は授業者が確認・修正できます。

## APIキーなしで使う

1. 「中2 理科｜電流とその利用」を読み込みます。「高校 数学Ⅱ｜三角関数」では別単元の評価規準を試せます。
2. 評価規準を生成し、表の内容を確認・承認します。
3. 指導上の追加観点を選択し、規準を生成して確定します。
4. 架空の理科授業の文字起こしを確認します。Zoom VTT・TXT・DOCX・CSV・テキスト付きPDFを選択、ドロップ、または貼り付けできます。
5. 「端末内分析を開始」を押します。サンプルと実際の授業記録を同じルールで処理し、発問・応答の件数、原文から抽出した観点別の根拠候補と時刻、改善提案を表示します。APIキーと学校管理者によるシステム設定は不要です。
6. PDFをダウンロードします。保存を押した評価は同じブラウザーの履歴から開けます。

サンプル本文は [sample-lesson.txt](public/sample-lesson.txt) にあります。CSVはUTF-8を使います。見出し `time,speaker,text` または `時刻,話者,発言` を認識します。話者が空欄の場合は未確認として扱います。文字起こしは10万文字、1行7500文字、ファイル15 MBが上限です。スキャンPDFのOCRには対応していません。

## GitHub Pagesへの公開

1. GitHubの `hakunou22hr` アカウントで、空の公開リポジトリ `ai-lesson-evaluation-accelerator` を作成します。
2. **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。空のリポジトリでPages設定が出ない場合は手順3の後に設定し、手順4で再実行します。
3. このソースを `main` にプッシュします。アーカイブから始める場合は以下のコマンドを使います。既存のコミットやファイルがある場合は取得して差分を確認してから進めてください。

```bash
git init -b main
git add .
git commit -m "Add lesson evaluation accelerator"
git remote add origin https://github.com/hakunou22hr/ai-lesson-evaluation-accelerator.git
git push -u origin main
```

4. **Actions → Deploy GitHub Pages** が成功したことを確認します。初回の設定後は **Run workflow** から再実行できます。以降は `main` への更新で自動的にビルド・デプロイされます。
5. 公開予定URLは `https://hakunou22hr.github.io/ai-lesson-evaluation-accelerator/` です。公開状態はActionsの実行結果と実際のサイトで確認してください。

## 任意・学校管理者向けの外部AI設定

学校の情報管理方針に沿って、OpenAIへの外部送信、API側の保持条件、利用者の範囲、費用を事前に承認してください。OpenAIとCloudflareの管理アカウントを利用します。

1. `wrangler.toml` の `APP_ORIGIN` を公開フロントエンドのオリジンに設定します。パスと末尾スラッシュは付けません。承認後に `AI_ENABLED` を `"true"` にします。
2. Wranglerを使ってWorkerをデプロイし、秘密変数を対話入力で登録します。利用コードは十分に長くランダムな値を発行し、承認した教員にだけ配布してください。入力値はリポジトリに保存しません。

```bash
npx wrangler login
npx wrangler deploy
npx wrangler secret put OPENAI_API_KEY
npx wrangler secret put ACCESS_CODE
```

3. GitHubの **Settings → Secrets and variables → Actions → Variables** に、公開可能なWorkerのHTTPS URLを `VITE_AI_ENDPOINT` として登録します。パス `/evaluate` はアプリが追加します。Actionsワークフローを再実行します。
4. 公開サイトの「設定」で利用コードを入力し、送信条件を確認します。架空のデータで本番経路を検証した後、承認した用途に限って利用してください。
5. APIプロジェクトの費用・使用量を監視してください。Workerはロケーションごとに学校全体で毎分50リクエストに制限します。1回の分析でも分割数の分だけリクエストを消費します。学校単位の共有コード方式のため、個人単位の認証・使用量制限は別途実装が必要です。停止時は `AI_ENABLED` を無効にして再デプロイするか、秘密変数を削除します。

## データ管理

- 既定の端末内分析とPDF生成はブラウザー内で完結します。授業記録は外部に送信されません。
- 本番AIでは規準の生成に匿名化した単元・目標・追加観点を使い、分析時は確認済みの文字起こしとルーブリックを学校管理Worker経由でOpenAI APIへ渡します。授業者名・授業日は構造化された授業情報から除外します。自由記述は送信前に目視確認してください。
- 匿名化はメールアドレス、区切り付き電話番号、敬称前の漢字列、指定語句に対応します。自動検出は補助機能です。
- Workerは本文をアプリのストレージへ記録せず、観測ログを無効化しています。OpenAI APIには `store:false` を設定します。APIの不正利用監視ログは通常最大30日間保持され、契約・法的義務等による例外があります。APIデータは既定でモデル学習に使われません。送信先の保持・削除については学校管理者を窓口とし、契約と [OpenAIのデータ管理](https://platform.openai.com/docs/guides/your-data) を確認してください。
- 履歴は明示的な保存操作で同じブラウザープロファイルに最大30件保存します。授業者名・根拠発言の抜粋を含むことがあります。履歴画面から削除できます。ブラウザープロファイルの利用者は閲覧可能です。共有端末での運用は学校の方針に従ってください。文字起こし全文や利用コードは履歴に保存しません。
- 人事評価や個人の正式な成績は自動確定しません。継続的な取組と学習の調整を確認するため、態度の自動判定は「判定不能」とします。

## 構成と制約

- React / TypeScript / Vite、GitHub Actions / Pages、任意のCloudflare WorkerとOpenAI API。
- `src/domain.ts` の資料カードが参照先を管理します。中2理科の電流と高校数学Ⅱの三角関数に単元対応の記述があり、その他は汎用規準案と公的資料リンクを表示します。全校種・全教科の本文検索や資料照合は実装していません。学習指導要領の正式本文・解説と規準案は別に表示します。改訂時は資料カードを更新してください。
- 端末内分析は全行を走査し、明示された話者、発問・応答の並び、規準や目標の語句などを使います。発言候補は各観点最大3件です。既定の「教師の発問の質」では、根拠を尋ねる発問に続き理由を示す表現があった場面をBの参考判定とします。他の観点と児童・生徒の3観点では、関連する発言候補があれば「確認待ち」、候補がなければ「根拠不足」と表示します。授業者はすべての評価を編集できます。
- 外部AIモードでは長文は全行を区間に分け、区間ごとの候補を統合します。評価欄の引用は本文に照合し、時刻は一致した行から付与します。分析本文の解釈や改善提案は授業者による確認が必要です。
- 分析・比較画面の長文は最初の10行を表示し、「続きを見る」で展開できます。PDFは同梱のNoto Sans CJK JPで描画した概要2ページと、評価理由・根拠・改善案の全文ページで構成されます。概要の「続きを見る」から全文へ移動できます。選択・検索用テキストレイヤーはありません。画像PDFのため、出力したレポート自身を文字起こしファイルとして再読込するにはOCRが必要です。

### Zoomの対話分析

Zoomの文字起こし（VTT）を直接選択できます。WEBVTTヘッダーを省いた抜粋や、Zoomの長い話者ラベルにも対応します。「Zoomの話者名をまとめて変更」で教師・生徒を割り当てると、指示・発問、最初の応答、教師の次の発問とそれに続く応答を、時刻付きの原文で表示します。話者ラベルを区別できる場合だけ、同じ話者ラベルの前後の応答を照合します。計測値は発言開始時刻同士の差です。発話終了後の待ち時間は示しません。疑問、説明、見直し、短い反応は発言表現に基づく手がかりです。PDFは対話の件数、時刻差の分布、発言の流れ、自己評価欄を表示します。

### ChatGPTの評価案を手動で取り込む

端末内分析後に「ChatGPTへの分析依頼をコピー」を押し、内容から識別情報を除いてから、利用が認められているChatGPTに貼り付けます。ChatGPTが返したJSONを同じ画面に貼り戻して「結果を照合して比較」を押してください。元の発言・行番号・時刻と一致する引用を確認し、観点別の提案と全体所見を別々に採用できます。採用結果は編集・PDF出力できます。依頼のコピーと結果の照合にはAPIキーが要りません。分析結果の文脈や妥当性は授業者が確認します。

次の授業で試す改善案も、根拠を照合して最大3件採用できます。場面ごとに残したい働きかけ、変えること、具体的な問い、確かめ方を確認できます。採用した案は履歴とPDFに含まれます。

### 目標が未設定の授業を振り返る

STEP 01で「目標なしでも振り返りを始める」を選び、文字起こしを読み込みます。役割が分かる話者を割り当てると、対話で確認できたこと、振り返りの観点案、次時に試す問いと確かめ方が表示されます。A・B・Cによる観点別評価が必要な場合は、授業情報に戻り、目標と規準を確定する手順を選んでください。
